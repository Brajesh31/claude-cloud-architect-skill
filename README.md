# Cloud Architect

A multi-cloud architecture skill for designing secure, resilient, scalable, and cost-aware infrastructure across AWS, Microsoft Azure, and Google Cloud.

## Capabilities

- Design cloud and multi-cloud architectures.
- Apply Infrastructure as Code with Terraform, OpenTofu, CloudFormation, Bicep, CDK, and Pulumi.
- Evaluate networking, identity, security, resilience, and disaster recovery.
- Design serverless, microservices, event-driven, and data architectures.
- Apply FinOps practices, cost allocation, and resource optimization.
- Use policy-as-code and GitOps patterns.

## Included resources

The repository includes `SKILL.md` and an implementation playbook under `resources/`. Consult the playbook for detailed design workflows and checklists.

## Usage

Use this skill when planning a cloud platform, reviewing architecture options, designing infrastructure automation, or optimizing reliability and cost. Start with workload requirements, constraints, threat model, compliance needs, and expected growth. Validate designs against the selected provider's current service limits and pricing.
